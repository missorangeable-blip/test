<Todoアプリ>
Flaskを使用して開発したTodo管理アプリです。

------主な機能------
　・タスク追加
　・タスク削除
　・タスク編集
　・完了チェック
　・優先度設定
　・締切日設定
　・期限切れ判定
　・タスク検索
　・JSON保存

------使用技術------
　・Python
　・Flask
　・HTML
　・CSS
　・JSON
　・Git
　・GitHub

------学習内容------
・FlaskによるWebアプリ開発
・CRUD機能の実装
・JSONによるデータ保存
・Git/GitHubを使用したバージョン管理

------demo------
・実際にアプリを体験できます　https://todo-app-ev8b.onrender.com
